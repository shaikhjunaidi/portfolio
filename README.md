# Personal Portfolio Website

A modern, premium, and fully responsive personal portfolio website built for a Computer Applications student focused on becoming a Python Web Developer. 

## Features

- **Modern UI/UX**: Clean, elegant, and professional design featuring glassmorphism and gradient backgrounds.
- **Fully Responsive**: Adapts seamlessly to all devices (mobile, tablet, desktop) using Bootstrap 5.
- **Dark/Light Mode**: User preference toggle with `localStorage` memory.
- **Interactive Animations**: Includes smooth scrolling, `AOS` (Animate On Scroll), `Typed.js` text typing, and an interactive `Particles.js` background.
- **Dynamic Contact Form**: Connected via Formspree to seamlessly receive emails without a backend.
- **Project Showcase**: Highlights featured projects like the "Crop Prediction System" with listed tech stacks and features.

## Tech Stack

- **HTML5** for semantic structuring
- **CSS3** with custom variables for themes
- **JavaScript** for interactivity and logic
- **Bootstrap 5** for grid and responsive components
- **Font Awesome** for scalable vector icons
- **AOS** for scroll animations
- **Typed.js** for hero typing animations
- **Particles.js** for background interaction

## Setup & Deployment

This is a purely static website. It does not require any build tools, bundlers, or backend servers to run.

### Local Development
1. Clone the repository: `git clone https://github.com/shaikhjunaidi/portfolio.git`
2. Open the `index.html` file in any modern web browser.
3. *Note: Ensure you are connected to the internet to load the CDN libraries.*

### Deploying to GitHub Pages
1. Go to the Settings tab of your GitHub repository.
2. Navigate to the **Pages** section on the left sidebar.
3. Under **Build and deployment**, set the Source to **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then click **Save**.
5. Your portfolio will be live at `https://shaikhjunaidi.github.io/portfolio/` within a few minutes!
